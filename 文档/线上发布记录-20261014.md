服务器后端与管理后台已发布至 https://wxagentshow.mguit.com 。部署代码版本为 `292d65d`，分支为 `feature/luxai-memory-multi-session`。数据库由 V49 升至 V52，服务健康检查为 `UP`。微信小程序新版客户端尚未上传、提交审核或发布。

## 发布和数据核对

- 先备份数据库、旧程序包、管理后台、生产环境变量、systemd 与 Nginx 配置；备份失败会阻止本次发布，没有使用仓库中会忽略备份失败的 Docker 部署脚本。
- 将备份恢复到本地隔离数据库，实际演练 V50/V51/V52，全部成功。完成后已删除该临时数据库和本地数据库备份副本。
- 暂停新的 Agent 写请求，保留历史、轮询和微信消息推送入口；确认无排队/运行中的图片任务、无现存后端连接后停止服务。
- 停止前再次备份数据库，替换程序并启动。约 27.6 秒后健康检查恢复，随后恢复生成入口。
- 重启前后均为 116 个用户、98 个会话、2729 条消息、116 个豆子账户，豆子余额合计 69634。此对比发生在创建上线测试账号之前。
- 生产 `.env` 与 systemd 服务配置逐字节比对一致；微信配置、加密主密钥、上传目录和 Redis 沿用原配置。
- 管理后台先复制新资源，再替换首页，保留旧哈希资源以兼容已打开的页面。线上首页 SHA256 与本次构建一致。

## 构建与边界

- 后端使用此前完整 Maven 测试及打包通过的产物。
- 后台 Vite 生产构建通过。原 `npm run build` 的旧 `vue-tsc` 与已安装 TypeScript 不兼容；使用隔离的 TypeScript 5.1.6 / vue-tsc 1.8.27 检查后，当前版本和基线版本均存在相同的 61 项既有类型诊断，无新增诊断。没有把完整类型检查标为通过。
- 主动断开 SSE 的三次检查产生三条 `Broken pipe / AsyncRequestNotUsableException` 日志；对应后台任务均继续完成，未形成业务失败。现有通用异常处理仍将断流记录为 ERROR。
- 尚未进行微信小程序新版上传发布、手机真机验收或真实支付订单验收。服务器能力已生效；新模型选择、多会话列表等新版客户端界面需发布小程序后使用。
