## 1 通用说明

### 1.1 访问地址

后端默认监听 8080 端口。线上由 nginx 统一转发，规则如下：

| 请求路径 | 转发方式 | 用途 |
|---|---|---|
| `/api/mobile/**` | 原样转给后端 | 小程序端接口 |
| `/api/pay/notify`、`/api/common/upload` | 原样转给后端 | 支付回调、小程序上传图片 |
| 其余 `/api/**` | 去掉 `/api` 前缀后转给后端 | 后台管理端接口 |
| `/profile/**` | 原样转给后端 | 已上传文件的访问地址 |

本文档写的都是后端的真实路径。后台管理端接口从浏览器访问时要在前面加 `/api`，例如 `/system/user/list` 实际请求的是 `/api/system/user/list`。小程序端接口的路径本身已经带 `/api/mobile`，不用再加。

### 1.2 登录和令牌

后台和小程序是两套独立的登录，令牌不能混用。

| 项目 | 后台管理端 | 小程序端 |
|---|---|---|
| 登录接口 | `POST /login`，先调 `GET /captchaImage` 取验证码 | `POST /api/mobile/wx/login` 或 `POST /api/mobile/wx/phoneLogin` |
| 令牌有效期 | 12 小时 | 访问令牌 2 小时，刷新令牌 30 天 |
| 续期 | 重新登录 | `POST /api/mobile/refreshToken` |
| 未登录或令牌过期 | HTTP 状态码 401 | HTTP 状态码 200，返回体的 code 为 401 |

登录后每个请求都要带请求头：

```
Authorization: Bearer <token>
```

### 1.3 返回格式

除了流式接口和第三方回调，所有接口都返回同一种 JSON 结构：

```
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数校验不通过，msg 里是具体原因 |
| 401 | 未登录或登录已过期 |
| 403 | 没有权限 |
| 429 | 请求太频繁，被限流 |
| 500 | 业务处理失败或系统异常，msg 里是原因 |

后面每个接口的“返回”一栏只写 data 部分。

### 1.4 分页

列表接口用 `pageNum`（页码，从 1 开始）和 `pageSize`（每页条数）分页，返回的 data 是：

```
{
  "records": [],
  "total": 100,
  "size": 10,
  "current": 1,
  "pages": 10
}
```

后面写“分页<X>”的地方，表示 records 里的每一项是 X。

### 1.5 权限标识

后台接口标注的权限标识，对应“菜单管理”里按钮的权限字符。角色勾选了对应的菜单或按钮，这个角色下的账号才能调用。超级管理员不受限制。

### 1.6 流式接口

对话类接口用 SSE(`text/event-stream`)逐条推送内容，客户端要按事件流读取，不能当成普通 JSON 解析。nginx 对这些路径已经关闭了缓冲。

### 1.7 文件上传

上传接口用 `multipart/form-data`。单个文件不超过 10MB，单次请求不超过 20MB。

### 1.8 在线调试

开发环境启动后端后，可以打开 `/swagger-ui.html` 在线调试，`/v3/api-docs` 是 OpenAPI 定义。生产环境这两个地址默认关闭。随文档提供的 `openapi.json` 可以直接导入 Apifox 或 Postman。

## 2 后台管理端接口

### 2.1 登录认证

后台登录、退出、当前用户信息和菜单路由。

#### 2.1.1 获取图形验证码

```
GET /captchaImage
```

认证：免登录

返回验证码图片(Base64)和 uuid，登录时把 uuid 和用户输入的验证码一并提交。验证码 2 分钟内有效。

**返回**

data 是一个对象，含 `uuid`（验证码标识）和 `img`（验证码图片，Base64）。

#### 2.1.2 用户登录

```
POST /login
```

认证：免登录

用户登录接口，返回JWT Token

**请求体**（`application/json`）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `username` | `string` | 是 | 用户名 |
| `password` | `string` | 是 | 用户密码 |
| `code` | `string` | 否 | 验证码 |
| `uuid` | `string` | 否 | 唯一标识 |

**返回**

data 是一个对象，含 `token`（后台令牌）。

#### 2.1.3 退出登录

```
POST /logout
```

认证：需登录（后台令牌）

删除服务端会话使令牌立即失效

删除服务端 Redis 会话，使该令牌立即失效

**返回**

data 为空。

#### 2.1.4 获取用户信息

```
GET /getInfo
```

认证：需登录（后台令牌）

获取当前登录用户的基本信息、角色和权限

**返回**

data 是一个对象，含 `user`（当前用户）、`roles`（角色列表）、`permissions`（权限标识列表）。

#### 2.1.5 获取菜单路由

```
GET /getRouters
```

认证：需登录（后台令牌）

获取当前用户可访问的菜单树，用于前端动态路由

**返回**

data 类型 `SysMenu[]`，其中 `SysMenu` 的字段见附录。

| `genYesterday` | `integer(int64)` | 昨日产出（用于算环比） |
| `activeCreatorsToday` | `integer(int64)` | 今日活跃创作用户（今日有产出的去重用户数） |
| `incomeTotal` | `number` | 累计收入（元） |
| `incomeToday` | `number` | 今日收入（元） |
| `memberActive` | `integer(int64)` | 有效会员数 |
| `trend` | `TrendItem[]` | 近 30 天趋势（按天，缺失天补 0） |
| `bean` | `BeanEconomy` | 豆子经济 |
| `modelDist` | `NameCount[]` | 各模型产出占比 |
| `typeDist` | `TypeCount[]` | 各产出类型占比 |
| `recentOrders` | `RecentOrder[]` | 最近 5 笔订单 |
| `recentGens` | `RecentGen[]` | 最近 5 条产出 |
