# 小程序模型档位展示

小程序对话、出图卡片、选择列表和计费说明统一使用“轻 / 中 / 高”。生成页复用同一选择器。真实模型名称、部署 ID、供应商只用于后台管理和内部调用。

## 配置与接口

后台模型管理新增“小程序档位”，可选轻、中、高。档位绑定模型记录，不跟随默认状态、列表顺序或价格变化；新增模型默认中。原模型 ID、启用状态、默认选择、收费和任务快照不变。

V53 只新增 `sys_ai_model.display_tier` 字段并初始化档位：

| 现有模型 | 初始公开档位 |
| --- | --- |
| GPT-6.1 Sol | 高 |
| GPT Image 2.5 Sunburst | 高 |
| GPT Image 2.5 Flare | 中 |
| 其他现有图片模型 | 轻 |
| 其他模型（含停用的 GPT-5.6 Sol） | 中 |

这些是产品展示标签，不代表实测速度或质量承诺，可在后台调整。

`/api/mobile/agent/models` 的 `modelName` 与 `displayTier` 都只返回档位，不再返回 `provider`、`modelDeployment`。生成参数接口的 `modelName` 也只返回档位并删除 `provider`。任务轮询和会话恢复投影不再返回 `modelName`，内部任务快照保留真实名称用于重试和审计。

前端严格允许轻、中、高三个标签；旧接口或异常值统一显示中，不回退到真实名称。
